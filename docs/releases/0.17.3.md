# 0.17.3 — Navigation and recovery fixes

First package from the [end-to-end UI/UX audit](../ui-ux-audit-2026-10-17.md)
and [updated phased roadmap](../roadmap.md).

- Find refreshes late-loading and newly connected nodes without losing keyboard selection.
- Back closes About instead of leaving Map or Terminal; Escape preserves the selected node.
- Dismissed map errors stay quiet for the same problem category, with Retry and a direct Netgraph fallback.
- Empty Netgraph explains filtering/window states and offers scoped recovery actions.
- Follow keeps Hold, close, Next and Inspect reachable on short landscape screens.
- Labs pause/reset/resume feedback stays readable, with focused screen-reader announcements instead of a per-packet queue.
- Existing Android 1.1.2 receives the hosted fixes; no new APK or signing identity.

Packet/audio timing, confirmed topology, saved settings and privacy remain unchanged. Hard build-size caps remain removed; runtime, performance and security checks remain. The remaining roadmap phases are planned.
