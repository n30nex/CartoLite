# CartoLite Android 1.1.3

Chronoscope now appears in the starting-view choices, is remembered as the last view, and shares the correct Canada URL. The shared web dock opens Map, Netgraph, Terminal, Chronoscope and Labs.

Package and original signing certificate are preserved. Install over 1.1.2 to retain app data and preferences. The hosted web frontend supplies the visualization; this native update fixes view restoration, sharing and loading labels.

Publication requires the exact successful main CI candidate, API 26/36 checks and certificate verification. Physical-device testing has not been performed for this release.
