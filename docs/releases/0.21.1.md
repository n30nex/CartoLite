# CartoLite Canada 0.21.1

- Chronoscope, Firehose and Pachinko Home views fit narrow phones and short landscape screens around permanent controls. Manual orbit, zoom and framing survive appearance changes.
- Gesture hints reflect touch/mouse input and the current scene mode.
- Terminal keeps Display, view switching and settings dismissal readable with low-contrast custom palettes; Reset is easier to find. Saved colours remain intact.
- Netgraph's desktop dock returns to the bottom edge without the map attribution gap.
- Long packet inspectors retain a visible close button. Sound icons and count labels are consistent across experimental pages; Pachinko bucket counts no longer announce every packet to screen readers.
- Labs navigation has clearer spacing, a readable phone picker and synchronized active markers. Mesh Loom and Villages labels are stronger and honor enlarged text.

The signed Canada Android 1.1.5 app receives hosted-page improvements; its package and signing identity are unchanged.

All automated validation and screenshots run in Actions. Existing packet/audio timing, physics, topology, privacy, graphics recovery and performance limits are retained. Exact tested artifacts and final verification are recorded with the published release.
