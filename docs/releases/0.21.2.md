# CartoLite Canada 0.21.2

- A cohesive CartoLite interface across Map, Netgraph, Chronoscope, Firehose, Pachinko and all four Labs, inspired by Beacon's restrained palette approach.
- Four coordinated palettes in Display: Aurora, Glacier, Ember and Violet. Each supports dark and light panels; Aurora also has the warm Streets/Paper companion.
- Consistent menus, fields, focus/selected states, inspector text, status colours and small control corners.
- Packet swatches now stay readable when panel and scene brightness differ. Chronoscope recent activity, Pachinko bucket labels and the Loom legend follow the correct colour context.
- Existing saved preferences migrate safely. Palettes synchronize across ordinary views and tabs; Terminal keeps its custom colours and fonts.

Route/packet meaning, sound timing, camera state and physics are unchanged. The
Canada Android 1.1.5 package remains unchanged and receives the hosted UI update.

All automated validation and synthetic screenshots run in Actions. Release
qualification, exact artifacts and public deployment evidence accompany the
published release.
