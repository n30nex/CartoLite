# CartoLite usability and recovery audit · 5 September 2026

Scope: the live map, Netgraph, Labs, shared client recovery, Finder, and the existing release/deployment path. The inspected production baseline was v0.10.6 (`dd24d3165ae4185ddcb510858a19af40fb977690`), with healthy readiness, zero drops, zero restarts, and an empty ingest queue. This is a focused product audit, not a complete security or accessibility certification.

## Changes implemented in v0.10.7

| Finding | Impact | Resolution |
| --- | --- | --- |
| Map navigation and controls were independently positioned at the top corners. At 1280px the controls covered Netgraph navigation and live status. | Navigation became difficult to reach on common laptop widths. | A native wrapping flex toolbar keeps both groups separate; phone status text stays visible. |
| The compact toolbar's label-hiding rule also overrode labels inside the phone layers menu. | The expanded menu showed unexplained icons. | The menu's label rule now takes precedence, while compact toolbar controls stay small. |
| Netgraph's landscape details panel started at the same height as the controls and covered Find after selection. | Inspecting one node blocked finding another by touch. | Place details below the control row and keep Finder/Sound popovers above details; verify both keyboard and pointer selection with details open. |
| Finder only moved focus to its first result; Up/Down could not choose subsequent results consistently. | Keyboard users lost typing focus and could not use the expected selection keys. | Shared combobox behavior with active-descendant announcements, Up/Down selection, Enter, and Escape focus restoration. Labels remain text-only and searches stay local. |
| A permanently closed EventSource only changed the status indicator. Successful snapshots reset the retry counter even if the new stream was refused again. | A transient HTTP failure could strand a view or cause repeated retries without increasing delay. | Restart refused streams through the existing single-flight snapshot recovery, increase backoff, and reset it only when a stream opens. |
| State fetches had no deadline. | One stalled response could block both startup and every later recovery request. | A 15-second abort deadline covers response and body retrieval, preserves caller cancellation, and clears its timer on completion. |
| Startup errors showed technical messages without an action. | Visitors had no visible way to retry Map, Netgraph, or Labs. | A consistent explanation and native Try again link reload the same view with saved preferences. |

## Validation and deployment

The existing GitHub Actions gates remain the build/test authority. Added regressions exercise refused streams, malformed resets, request deadlines/cancellation, keyboard Finder selection on Map and Netgraph, failed-start retries on all three views, and non-overlapping toolbar layouts from 320px through 1440px.

The unchanged baseline also exhausted the default 30-second deadline during its full visual journey; traces showed progress through terrain transitions and subsequent controls before the overall cutoff. The visual and large-topology journeys now use Playwright's per-test slow annotation. Individual assertion deadlines and explicit startup, frame, long-task, and application-work performance thresholds remain unchanged.

Deployment uses the exact published image digest, a protected configuration/checkpoint backup, recreation of only the existing CartoLite service, public health/readiness and SSE verification, and live browser checks. No backend schema, broker subscription, public data fields, database, analytics, or native APK change is part of this release.
